**Cómo usar el programa

Para poder ejecutar el proyecto debe clonar el proyecto y abrirlo en Apache Neatbeans.
Una vez abierto en Neatbeans debe abrir la carpeta "src" y escoger el archivo "EdExponenciaciónNumero" y presionar "F6"
